# Conway's Game Of Life  

A rendition of Conway's Game of Life to test out and learn various c++ systems in preperation for building a game:  
- cmake - wound up not being able to make cmake function properly within the nixos environment so worked directly with make   
- gtest - also could not make this work in nixos environment. Will look for another method for testing on another project   
- sfml  

### How to install:  

- git clone the repo  
- run make command in app directory  
- run the ConwayGOL.out  

### Results and Takeaways  

I found that this app was simpler than I had anticipated. But it has started my learning on visual output using the SFML framework. There is some refactoring that I would like to do but probably never will. I love watching the visual out put of this app. My favorite is when the life forms do this weird explosion thing that looks like a flower.  
Also, as much as I love the nixos system, I hate programming on it. It is so fussy with the shells and pathing and things not working as anticipated. Maybe I will setup a debian based VM just for programming but that seems ridiculous to do.
